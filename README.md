# loophole-site

Public pages for the LOOPHOLE iPhone game, served by GitHub Pages.

- `privacy.html`: privacy policy (App Store Connect → Privacy Policy URL)
- `support.html`: support page (App Store Connect → Support URL)
- `index.html`: landing page

The source of truth is `site/` in the game repo. Copy changes here to publish them.

- `play/`: retired. The playable build moved to https://matthewbove-rgb.github.io/Loophole-public/ (repo `Loophole-public`); `play/` now redirects there and its service worker clears the old offline copy.
